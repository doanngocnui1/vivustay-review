# Thư mục lưu trữ file APK phát hành

Đặt file APK vào đây và đổi tên tương ứng với đường dẫn trong file `version.json`.

Ví dụ:
- Đặt file `viestay-v2.0.1.apk` vào đây.
- Khi push lên GitHub, file sẽ truy cập được tại:
  `https://doanngocnui1.github.io/Vivustay2.0_mobile-app/releases/viestay-v2.0.1.apk`
